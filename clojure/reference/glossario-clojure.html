Glossário Clojure

Termos canônicos deste workspace de aprendizado.

Fundamentos

Forma (form)
Qualquer expressão válida em Clojure — um átomo, uma lista, um vetor, um mapa ou uma função. Tudo que você avalia no REPL é uma forma.
Evitar: comando, statement, linha de código
REPL
Read-Eval-Print Loop: ciclo interativo que lê uma forma, avalia, imprime o resultado e espera a próxima. É o laboratório principal de Clojure.
Evitar: console, terminal genérico
Avaliação
Processo pelo qual o runtime transforma uma forma em um valor. Listas com operador na primeira posição são chamadas como função.
Notação prefixa
Operador vem antes dos operandos: (+ 1 2) em vez de 1 + 2. Parênteses definem a chamada, não apenas agrupam.
def
Cria um var nomeado no namespace atual, associando um símbolo a um valor. O valor persiste entre avaliações no REPL.
Evitar: variável mutável, atribuição
defn
Define uma função nomeada: cria um var cujo valor é uma função. Combina def com a lógica de fn.
Valor
Resultado de avaliar uma forma — número, string, coleção, função, nil, etc. Em Clojure, valores são imutáveis.

Este glossário cresce conforme você demonstra entendimento. Termos novos entram após uso correto, não após primeira exposição.
