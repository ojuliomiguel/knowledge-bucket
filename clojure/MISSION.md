# Mission: Clojure

## Why

Aprender Clojure como projeto pessoal — por curiosidade com programação funcional e como desafio intelectual. O objetivo prático é voltar a escrever código com confiança e, no médio prazo, construir uma API ou CLI.

## Success looks like

- Ler e escrever código Clojure no dia a dia sem depender de cola constante
- Construir uma API ou CLI funcional em Clojure
- Terminar *Clojure for the Brave and True*
- Usar o REPL como ferramenta natural de exploração e depuração

## Constraints

- Retorno após um período afastado — muita coisa foi esquecida, apesar de exercícios anteriores no repositório
- Preferência por mistura: lições curtas + prática no REPL + revisão de código existente
- Repositório de estudo já estruturado (`src/brave_clojure/`, `src/exercism/`, `src/katas/`, `slip_box/`)

## Out of scope

- Frameworks web completos (Ring, Reitit, Datomic) até recuperar fluência no núcleo da linguagem
- ClojureScript e frontend por enquanto
- Otimização prematura e padrões de produção avançados antes de dominar o básico funcional
