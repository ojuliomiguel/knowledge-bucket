Retomando o REPL

Missão: voltar a ler e escrever Clojure com confiança — projeto pessoal, programação funcional, e no futuro uma API ou CLI.

Você já escreveu Clojure neste repositório, mas passou um tempo afastado. Antes de coleções avançadas ou frameworks, precisamos reativar o hábito mais importante: avaliar formas no REPL e observar o resultado.

O que é uma forma?

Em Clojure, tudo que você digita é uma forma — uma expressão que o runtime pode avaliar. Números, strings, listas, vetores, mapas e funções são formas.

(+ 1 2)
;=> 3

Clojure usa notação prefixa: o operador vem primeiro, depois os operandos. Os parênteses não são decorativos — eles definem uma chamada de função. + é uma função; 1 e 2 são argumentos.

Compare com outras linguagens:

;; Clojure          ;; outras linguagens
(+ 1 2)             ; 1 + 2
(str "olá" "!")     ; "olá" + "!"

O REPL como laboratório

REPL significa Read-Eval-Print Loop. Você digita uma forma, o runtime avalia, imprime o resultado, e espera a próxima. É o ciclo de feedback mais rápido que existe em Clojure.

Prática agora: na pasta clojure/, rode clj no terminal. Avalie cada forma abaixo, uma por uma. Antes de pressionar Enter, tente prever o resultado. 
(+ 10 5)
(* 3 4)
(str "Clojure" " " "2026")
(- 100 37)

def e defn

def associa um nome a um valor no namespace. Não é uma variável mutável — é um var que aponta para um valor imutável.

(def pi 3.14)
pi
;=> 3.14

defn define uma função nomeada:

(defn dobrar [n]
  (* n 2))

(dobrar 7)
;=> 14

A forma [n] é a vetor de parâmetros — lista os nomes que a função recebe. O corpo da função é a última expressão; seu valor é o retorno (não precisa de return).

Prática agora: no REPL, defina uma função celsius-para-fahrenheit que recebe c e retorna (+ (* c 1.8) 32). Teste com 0 e 100.

Verificação rápida

Responda de memória antes de clicar em verificar.

1. O que (+ 1 2) devolve ao ser avaliado?
2. O que (def x 5) faz principalmente?
3. Em (defn somar [a b] (+ a b)), o que é [a b]?
